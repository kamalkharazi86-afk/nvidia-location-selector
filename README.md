# NVIDIA Location Selector Clone

An exact pixel-perfect, responsive replica of the official [NVIDIA Location Selector](https.nvidia.com/location-selector/) built with HTML5, CSS3 (Vanilla CSS with official NVIDIA design system tokens), and modern JavaScript.

## Features
- **Official NVIDIA Design Aesthetics**: Recreates the crisp dark theme, NVIDIA Green (`#76B900`) accents, typography (Inter), and SVG icons.
- **Real-Time Instant Search**: Instant filtering across country names, native names, and languages.
- **Interactive Region Tabs**: Filter locations by Americas, Europe, Asia Pacific, and Middle East & Africa.
- **Comprehensive Country List**: Complete location options with country flag identifiers and language links.
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop viewports.

## Running Locally

Simply open `index.html` in your web browser or serve it using any HTTP server:

```bash
npx serve .
```
